        to avoid too many try and catch
         we use ' async handlers ` - it is used when a route has to do something that takes time
                                    then we will use async and await , we have to use try and catch for error 
                                    so to avoid this at every route we use async handler 

                                        const asyncHandler = (requestHandler) =>{
                                                return ( req , res , next) => {
                                                        Promise.resolve(requestHandler(req, res, next))
                                                        .catch(next) ; 
                                                }
                                        }

14) bcyrpt - hashes password . If someone steals your database , they cannot directly see user's password 
        use a pre function before saving user data , in which if a user has changed password then we will hash it .
        userSchema.pre("save", async function(){
                if(!this.isModified("password") return next()) 
                this.password = await bcyrpt.hash(this.password , 10) 
                next() ; 
        })
