jwt token -      is a secure ,compact standard used to securely transmit information    between parties as json . It is primarily used for authentication and authorization in web applications and apis , allowing a user to login once and access protected data without filling credentials again 

why we need jwt token - 
    when the user login , server verifies the credentials .
    Now the question is how does the server remembers that this user is logged in
    future requests . 
        1) by checking the login data from database which is hectic 
        2) JWT tokens 
            when the user login , server provide browser it a token and every time any request shows up server just verifies the token each time 

jwt token is just a string . 
    it has 3 parts - header , payload , signature 
        a) header tells us (algo used , jwt type)
        b) payload contains information inside the token 
        {
            "_id": "2422" 
            "email" : "aayobachotumhebataiye@gmail.com" 
            "username" : "modistein" 
        }this data is called "claims"
        this is open to all so do not put any secretive data into it 
        c) signature this tells that token has been generated by your own server
        becuase it contains the secret key 

Types of JWT tokens
Access Token - short lived , contains user info and used to access protected route. it is given to the browser
const generateAccessToken = function(){
    return jwt.sign({
        _id : this.id , 
        email: this.email ,
        username : this.username
    },
    process.env.ACCESS_TOKEN_SECRET ,
    {expiry: process.env.ACCESS_TOKEN_EXPIRY
    }
    )
}
Refresh Token - long lived , used only to generate a new access token  . stored in database
