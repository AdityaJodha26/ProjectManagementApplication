what is nodejs - 
        Node.js — Quick Summary
        Node.js is a runtime environment that allows you to run JavaScript outside the browser.
        It is commonly used to build the backend/server of web applications.
        JavaScript = programming language.
        Node.js = environment that runs JavaScript on the server.
        How it works
        Frontend (React)
            ↓
        HTTP Request
            ↓
        Node.js Backend
            ↓
        Business Logic
            ↓
        Database
            ↓
        Node.js
            ↓
        Response → Frontend
        Why use Node.js?
        Build APIs
        Handle authentication
        Connect to databases
        Build real-time apps
        Handle file uploads
        Build SaaS/e-commerce backends
        Use JavaScript across both frontend and backend
        Node.js + Express
        Express.js is a framework that makes building Node.js servers and APIs easier.
        Your typical backend stack:
        JavaScript
        ↓
        Node.js
        ↓
        Express.js
        ↓
        REST API
        ↓
        MongoDB / PostgreSQL
        One-line definition:
        Node.js allows JavaScript to run on the server, making it possible to build backend applications with JavaScript.

backend flow -
        Frontend
        ↓
        HTTP Request
        ↓
        Node.js Server
        ↓
        Route
        ↓
        Middleware
        ↓
        Controller
        ↓
        Service / Business Logic
        ↓
        Database
        ↓
        Response
        ↓
        Frontend

        What each does:
        Route → decides which function handles the request.
        Middleware → authentication, validation, etc.
        Controller → handles the request/response.
        Service → contains the application's business logic.
        Database → stores and retrieves data.
        Response → sends the result back to the frontend.


sending and creating email - 
        Your code has 3 main jobs:
        Mailgen → Creates email content
        Nodemailer → Sends email
        Mailtrap → SMTP server for testing emails
        sendEmail()
        This is the main reusable function:
        options
        ↓
        Mailgen creates HTML + text
        ↓
        Nodemailer connects to SMTP
        ↓
        sendMail()
        ↓
        Email sent
        It gets SMTP credentials from .env:
        MAILTRAP_SMTP_HOST
        MAILTRAP_SMTP_PORT
        MAILTRAP_SMTP_USERNAME
        MAILTRAP_SMTP_PASSWORD
        Email content functions
        emailVerificationMailGenContent() → creates email verification content.
        forgotEmailMailGenContent() → creates password reset content.
        They don't send emails; they only create the content.
        Overall flow
        User registers
            ↓
        Create verification URL
            ↓
        Generate email content
            ↓
        sendEmail()
            ↓
        Nodemailer
            ↓
        Mailtrap
            ↓
        User receives email
        Remember:
        Mailgen = make the email → Nodemailer = send the email → Mailtrap = SMTP service used for testing.
